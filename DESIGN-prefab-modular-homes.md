## Positioning & feel
Architectural, precise, optimistic — engineering you can live in.

## Palette & accent discipline
Preset palette: deep green #14532d / gold #ca8a04. Gold for CTAs and spec-table highlights; let the architecture photography breathe.

## Typography
Preset pairing: **Sora + Inter** (weights wired automatically).
Optional premium upgrade: **Geometric Modern — Outfit + Work Sans** — set `fontDisplay`/`fontBody` AND
`fontsHref: "https://fonts.googleapis.com/css2?family=Outfit:wght@400;500;600;700;800&family=Work+Sans:wght@400;500;600;700;800&display=swap"` (this family set needs an explicit URL).

## Navigation & hero
Static hero + Request-a-Catalog CTA — one hero-grade prefab exterior. Overlay nav.
- Primary CTA: **"Request a Catalog"** | Secondary: **"Book a Site Consultation"**
- Form strategy: **premium — popup inquiry modal from CTAs; embedded form only on the contact page**

## Section rhythm
Follow the standard service/location templates (hero -> quick answer -> stats ->
sub-services -> signs -> pros/cons -> comparison -> why-us -> process -> gallery ->
area -> FAQ -> CTA) with the cadence rules from DESIGN-SYSTEM.md s6. Emphasize the
signature sections below; cut anything that would be filler for this niche.

## Signature sections (build these well)
1. Build process timeline: design, factory, delivery, install (ProcessSection with real durations)
2. Model gallery with spec chips (m2, bedrooms, energy class) + lightbox
3. Cost factors section (master prompt 12.18) — modular buyers research hard
4. Factory/quality split section — precision shots build the engineering story

## Imagery direction
Modern prefab exteriors, factory assembly, crane install moments, minimal interiors with wood tones.

**Never:** trailer-park connotations, renders that look like renders.

## Copy tone
Spec-literate but warm; talk timelines and energy bills, not buzzwords.

## Do
- ComparisonTable: modular vs traditional build — the niche's core question
- Count-up stats: build weeks, energy savings, homes delivered
- Big imagery margins; architectural photography needs air

## Don't
- Hiding prices entirely — show from-ranges or cost factors
- Cluttering hero with badges; one line + CTA
- Stock construction-site chaos shots
