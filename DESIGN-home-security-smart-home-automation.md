# DESIGN BRIEF — Home Security & Smart Home Automation

> **Wired in code:** `themePreset("security")` -> graphite #111827 / electric blue #2563eb | Sora + Inter | sharp corners, solid CTAs, solid nav.
> Read **DESIGN-SYSTEM.md** first — it carries the global rules (type, nav variants,
> buttons, motion, imagery, anti-slop checklist). This brief adds the niche layer.

## Positioning & feel
Precise, quietly technical, reassuring. Apple-store calm with a locksmith's credibility.

## Palette & accent discipline
Preset palette: graphite #111827 / electric blue #2563eb. Electric blue for CTAs, connection lines, and device states. Graphite restraint everywhere else.

## Typography
Preset pairing: **Sora + Inter** (weights wired automatically).
Optional premium upgrade: **Geometric Modern — Outfit + Work Sans** — set `fontDisplay`/`fontBody` AND
`fontsHref: "https://fonts.googleapis.com/css2?family=Outfit:wght@400;500;600;700;800&family=Work+Sans:wght@400;500;600;700;800&display=swap"` (this family set needs an explicit URL).

## Navigation & hero
Static hero — night exterior with warm windows + device inset, calm H1 about certainty (never fear). Solid nav.
- Primary CTA: **"Get a Security Assessment"** | Secondary: **"See Packages"**
- Form strategy: **standard — embedded hero/contact forms plus popup CTAs on inner pages**

## Section rhythm
Follow the standard service/location templates (hero -> quick answer -> stats ->
sub-services -> signs -> pros/cons -> comparison -> why-us -> process -> gallery ->
area -> FAQ -> CTA) with the cadence rules from DESIGN-SYSTEM.md s6. Emphasize the
signature sections below; cut anything that would be filler for this niche.

## Signature sections (build these well)
1. System components grid — camera/doorbell/sensors/hub cards with spec chips
2. Monitoring plan ComparisonTable (self vs pro monitoring) — the buying decision
3. Install process steps with realistic timing
4. Integrations row — platform logos only if genuinely supported

## Imagery direction
Device close-ups, app UI on a phone in hand, doorbell cam at door, warm-lit homes at night (safe, not scary).

**Unsplash starting queries** (verify every result actually shows the subject):
- "smart doorbell camera closeup"

**Never:** balaclava burglars, red alarm dramatics, server-room stock.

## Copy tone
Calm competence. Sell certainty and convenience; never sell fear (master prompt rule).

## Do
- Spec tables and exact compatibilities — buyers compare hard
- Use blueprint-thin lines and dots as a decorative motif
- Sharp radius, solid CTAs — precision language

## Don't
- Crime statistics as scare copy
- Red anywhere near the palette
- Vague military-grade claims
