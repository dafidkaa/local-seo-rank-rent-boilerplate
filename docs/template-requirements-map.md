# Template Requirements Map

This file maps the supplied mega prompt to the boilerplate implementation.

## Architecture

- Full multilingual static site: `src/pages/[lang]`
- Homepage and alternate homepage: `index.astro`, `home-page-2.astro`
- About, contact, legal, thank-you: fixed route files
- Service area hubs: `service-area.astro`, `service-area-hub-2.astro`
- Main services and secondary service categories: generated by `src/pages/[lang]/[slug].astro`
- Location landing pages: generated by `src/pages/[lang]/[location].astro`
- Subservices: generated by `src/pages/[lang]/[parent]/[child].astro`
- Blog hub and posts: `blog/index.astro`, `blog/[post].astro`

## Reusable Components

- `Header.astro`
- `Footer.astro`
- `Hero.astro`
- `EstimateForm.astro`
- `ServiceCard.astro`
- `LocationCard.astro`
- `ProcessSection.astro`
- `ReviewsSection.astro`
- `FaqSection.astro`
- `FinalCta.astro`
- `MobileCta.astro`

## SEO Components

- Metadata and canonical helper: `src/lib/seo.ts`
- Route helpers and slug generation: `src/lib/routes.ts`
- LocalBusiness, WebSite, Service, BreadcrumbList, FAQPage, Article, and ContactPage schema
- Sitemap endpoints: `src/pages/sitemap.xml.ts`, `src/pages/sitemap-index.xml.ts`
- Post-build sitemap artifact generation: `scripts/generate-sitemap.mjs`
- Robots endpoint: `src/pages/robots.txt.ts`

## Configuration Surface

The intended clone-and-customize file is `src/site.config.ts`.

It stores business variables, languages, brand settings, integrations, locations, services, and subservices. Blog posts live under `src/content/blog/` as markdown files with frontmatter.
