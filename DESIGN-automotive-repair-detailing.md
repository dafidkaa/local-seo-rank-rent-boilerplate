# DESIGN BRIEF — Automotive (Repair / Detailing / Tires)

> **Wired in code:** `themePreset("automotive")` -> slate #0f172a / signal red #dc2626 | Sora + Inter | sharp corners, gradient CTAs, solid nav.
> Read **DESIGN-SYSTEM.md** first — it carries the global rules (type, nav variants,
> buttons, motion, imagery, anti-slop checklist). This brief adds the niche layer.

## Positioning & feel
Technical confidence, garage-floor honesty, a little showmanship in the photography.

## Palette & accent discipline
Preset palette: slate #0f172a / signal red #dc2626. Signal red strictly for CTAs and accent rules — on slate it detonates; ration it.

## Typography
Preset pairing: **Sora + Inter** (weights wired automatically).
Optional premium upgrade: **Bold Statement — Bebas Neue + Source Sans 3** — set `fontDisplay`/`fontBody` AND
`fontsHref: "https://fonts.googleapis.com/css2?family=Bebas+Neue&family=Source+Sans+3:wght@400;500;600;700;800&display=swap"` (this family set needs an explicit URL).

## Navigation & hero
Static hero — one dramatic low-key shot (paint gloss or workshop light) + bold H1. Solid nav with phone-forward utility bar.
- Primary CTA: **"Get a Quote"** | Secondary: **"Book a Detail"**
- Form strategy: **standard — embedded hero/contact forms plus popup CTAs on inner pages**

## Section rhythm
Follow the standard service/location templates (hero -> quick answer -> stats ->
sub-services -> signs -> pros/cons -> comparison -> why-us -> process -> gallery ->
area -> FAQ -> CTA) with the cadence rules from DESIGN-SYSTEM.md s6. Emphasize the
signature sections below; cut anything that would be filler for this niche.

## Signature sections (build these well)
1. Before/after slider is MANDATORY on detailing pages (service.beforeAfter)
2. Transparent pricing table per package (wash/detail/correction tiers)
3. Shop gallery — equipment and bench shots prove capability
4. Brand/marque strip if real brands are serviced

## Imagery direction
Paint reflections macro, beading water, engine bays, workshop dramatic light, wheels detail. Dark, glossy, high contrast.

**Unsplash starting queries** (verify every result actually shows the subject):
- "car paint polishing closeup"
- "water beads car hood macro"
- "mechanic workshop dramatic light"
- "engine bay detail clean"
- "alloy wheel closeup gloss"
- "car headlight restoration"

**Never:** showroom stock supercars (unless serviced), oily chaos, salesman handshakes.

## Copy tone
Gearhead-fluent but readable; name processes (paint correction stages) plainly.

## Do
- Lean into dark sections — this niche supports 2 per page
- Sharp radius + condensed display upgrade pairing = motorsport energy
- Show real turnaround times near CTAs

## Don't
- Red backgrounds — red is for buttons only
- Speed-lines, checkered-flag kitsch
- Stretching one car photo across every section
