# DESIGN BRIEF — Custom Furniture & Joinery

> **Wired in code:** `themePreset("luxury")` -> ink #1c1917 / champagne #b45309 | Playfair Display + Inter | sharp corners, solid CTAs, overlay nav.
> Read **DESIGN-SYSTEM.md** first — it carries the global rules (type, nav variants,
> buttons, motion, imagery, anti-slop checklist). This brief adds the niche layer.

## Positioning & feel
Craft, provenance, patience. Wood grain macro, charcoal backdrops, champagne accents — a portfolio first, a website second.

## Palette & accent discipline
Preset palette: ink #1c1917 / champagne #b45309. Champagne bronze for hairline rules, CTAs, and numbered process steps. Never fills.

## Typography
Preset pairing: **Playfair Display + Inter** (weights wired automatically).
Optional premium upgrade: **Luxury Serif — Cormorant + Montserrat** — set `fontDisplay`/`fontBody` AND
`fontsHref: "https://fonts.googleapis.com/css2?family=Cormorant:wght@500;600;700&family=Montserrat:wght@400;500;600;700&display=swap"` (this family set needs an explicit URL).

## Navigation & hero
Static hero, overlay nav — one piece, perfectly lit, serif H1. The quietest, most gallery-like hero in the catalog.
- Primary CTA: **"Commission a Piece"** | Secondary: **"Visit the Workshop"**
- Form strategy: **premium — popup inquiry modal from CTAs; embedded form only on the contact page**

## Section rhythm
Follow the standard service/location templates (hero -> quick answer -> stats ->
sub-services -> signs -> pros/cons -> comparison -> why-us -> process -> gallery ->
area -> FAQ -> CTA) with the cadence rules from DESIGN-SYSTEM.md s6. Emphasize the
signature sections below; cut anything that would be filler for this niche.

## Signature sections (build these well)
1. Large-format portfolio gallery — one piece per viewport row, captioned (material, finish, year)
2. Materials story split sections — grain macro + a paragraph per timber
3. Commission process: consultation, sketch, build, delivery, with real lead times
4. Workshop tour band — dark section, tools and benches in low light

## Imagery direction
Joinery detail macro, wood grain, hand tools, workshop window light, finished pieces styled in real interiors.

**Unsplash starting queries** (verify every result actually shows the subject):
- "woodworking joinery detail macro"
- "walnut wood grain texture"
- "craftsman workshop window light"
- "handmade furniture in interior"
- "chisel hand tool woodwork"
- "dovetail joint closeup"

**Never:** flat-pack vibes, catalogue white-box shots, sawdust chaos.

## Copy tone
First-person plural, slow sentences, material vocabulary. Price as investment.

## Do
- Whitespace maximalism — one idea per section
- Gallery + lightbox everywhere; images at 3:2, minimum 1600px
- Popup inquiry only; an embedded form would cheapen the page

## Don't
- Discounts, urgency, countdowns — poison for this positioning
- More than 2 CTAs per page
- Sans-serif display override; the serif IS the brand
