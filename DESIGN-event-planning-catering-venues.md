# DESIGN BRIEF — Events (Planning / Catering / Venues)

> **Wired in code:** `themePreset("events")` -> plum #701a75 / rose #e11d48 | Playfair Display + Jost | round corners, solid CTAs, overlay nav.
> Read **DESIGN-SYSTEM.md** first — it carries the global rules (type, nav variants,
> buttons, motion, imagery, anti-slop checklist). This brief adds the niche layer.

## Positioning & feel
Celebratory and composed — the organized friend with impeccable taste. Romance in photos, precision in copy.

## Palette & accent discipline
Preset palette: plum #701a75 / rose #e11d48. Rose for CTAs and date-checking moments; plum holds structure. Photography supplies the rest of the color.

## Typography
Preset pairing: **Playfair Display + Jost** (weights wired automatically).
Optional premium upgrade: **Classic Elegant — Playfair Display + Inter** (full 400-800 weights — no fontsHref needed).

## Navigation & hero
Slider hero, overlay nav — three moments: venue dressed, table detail, candid celebration. Slow fades.
- Primary CTA: **"Check Your Date"** | Secondary: **"Plan Your Event"**
- Form strategy: **premium — popup inquiry modal from CTAs; embedded form only on the contact page**

## Section rhythm
Follow the standard service/location templates (hero -> quick answer -> stats ->
sub-services -> signs -> pros/cons -> comparison -> why-us -> process -> gallery ->
area -> FAQ -> CTA) with the cadence rules from DESIGN-SYSTEM.md s6. Emphasize the
signature sections below; cut anything that would be filler for this niche.

## Signature sections (build these well)
1. Portfolio gallery by event type (weddings/corporate/private) with lightbox
2. Package comparison table — inclusions per tier, honest pricing language
3. Planning timeline — from first call to last dance (ProcessSection)
4. Testimonial carousel with event photos as backgrounds

## Imagery direction
Dressed tables macro, ambient lighting, florals close-up, candid laughter mid-moment, venue wide shots at dusk.

**Unsplash starting queries** (verify every result actually shows the subject):
- "wedding table setting candles"
- "event venue fairy lights dusk"
- "catering plating elegant"
- "floral centerpiece closeup"
- "celebration toast candid"
- "banquet hall decorated wide"

**Never:** posed group grins, balloon-arch clipart aesthetics, harsh flash.

## Copy tone
Warm, organized, plural (your day, our checklist). Logistics made lyrical.

## Do
- Check-Your-Date as primary CTA — urgency without pressure
- Round corners + pill buttons; soft is the language
- Let one full-bleed image section breathe per page

## Don't
- Cramming every service into the hero
- Comic-energy script fonts
- Generic we-make-memories filler — name venues and menus
